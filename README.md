# iGraphics

## Game Description

**Pirate Adventure** is a 2D graphics-based game project developed using the **iGraphics library in C/C++**. The project demonstrates graphics programming, keyboard input, game states, character movement, battle mechanics, and interactive gameplay.

## Features

- Menu / game-state screens
- Player and enemy gameplay
- Keyboard controls
- Battle system
- Health / alive states
- Cannon and projectile mechanics
- Multiple levels

## Project Details

IDE: Visual Studio 2013

Language: C / C++

Library: iGraphics

Platform: Windows PC

Genre: 2D Action / Adventure

## How to Run the Project

Make sure you have the following installed:

- **Visual Studio 2013**
- **iGraphics Library** and its required dependencies

### Steps

1. Open **Visual Studio 2013**.
2. Go to **File → Open → Project/Solution**.
3. Locate and select the `.sln` file from the project folder.
4. Click **Build → Build Solution**.
5. Run the program using **Debug → Start Without Debugging**.

## How to Play

### Controls

- Use the keyboard controls implemented in the game to move the player and interact with the gameplay.
- Follow the on-screen instructions shown in the game.

### Game Rules

- The player progresses through the available game levels.
- Player and enemy states are updated during gameplay.
- Battle actions affect the health/state of the characters.
- Completing the required battle objectives allows the player to progress.
